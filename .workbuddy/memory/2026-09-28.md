### 统一更新纪律（用户拍板，已写入 MEMORY.md）
> 一处功能改动必须同步到所有适用树（R4/CU/VM），同步后各树独立回归。

本轮实操教训：
1. **`git apply` 对 CRLF 文件 + LF patch 会静默失败（返回 0 但不落盘）**——三树同步用 GNU `patch -p2 -l`（patch 头带 `a/<树名>/` 前缀时用 -p2 剥掉），apply 后必须 grep 验证内容真的落上。
2. 树间文件「规范化后 diff=0」的判断要先 `tr -d '\r'`，否则行尾差异会把 diff 放大几十倍。
3. E-LLM-004 掩码 ctx 上轮「两树同步」实际漏了 CU（agent.py 的 LLMClient）——本轮补齐；同步后要核对每个 hunk 真的落到每棵树。
