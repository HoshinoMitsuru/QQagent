# 小清澈 - 接入AI聊天 (Mitsuru-AiChat)

**版本**: 1.4.0  
**作者**: bilibili@嗅尘紫蝶  
**许可证**: MIT

这是一个专为 **SealDice (海豹骰子)** 设计的 JavaScript 插件。它接入了 DeepSeek / OpenAI 兼容接口，为群聊带来了一位名为“小清澈”的智能助手。

小清澈不仅支持 `.ai` 指令对话，还支持**中文前缀自动唤起**、**连续对话模式**，以及极具特色的**多人格切换**功能。

---

##  功能特性

*   ** 智能对话**: 支持 DeepSeek / OpenAI 兼容接口，10轮上下文记忆。
*   ** 多重人格**: 内置多种预设人格（如“小天使”、“星野光”、“小太阳”等），可根据场景切换性格和说话方式。
*   ** 自动唤起**: 支持配置关键词前缀（默认“小清澈，”），在群聊中直接@或提及即可唤醒。
*   ** 连续对话**: 支持连续对话模式，在设定时间内无需重复指令。
*   ** 群聊整合**: 能够识别群聊中的多人对话上下文，整合信息后进行回复。
*   ** 提示对象**: 群聊场景下，@回答的目标用户，适应群聊场景。

##  使用指南

###  基础指令

*   **`小清澈，`**: 唤起，注意使用中文逗号。
*   **`.ai reset`**: 清空当前会话的历史记录，重新开始。
*   **`.ai stop`**: 退出连续对话模式。
*   **`.ai list`**: 查看当前所有可用的人格列表。

###  人格切换系统

你可以通过指令让“小清澈”切换不同的性格设定：

**指令格式**: `.ai persona <人格名>`

**内置人格介绍**:

1.  **小天使 (默认)**
    *   **设定**: 15岁小男孩，天真烂漫，爱用颜文字。
    *   **特长**: 烹饪甜点、美声唱歌（擅长偶像梦幻祭）、运动。
    *   **关系**: 视用户为哥哥，性格阳光。
2.  **星野光**
    *   **设定**: 19岁文艺青年，心思细腻，略带忧郁。
    *   **特长**: 诗歌创作、文艺理论、神秘学。
    *   **关系**: 用户的同性恋人，说话文绉绉且华丽。
3.  **小太阳**
    *   **设定**: 18岁热血青年，擅长哲学辩论。
    *   **特长**: 青年黑格尔派、结构主义、齐泽克哲学。
    *   **关系**: 用户的同志/知己，柏拉图式爱情，喜欢讨论深刻思想。
4.  **启明星**
    *   **设定**: 17岁元气二次元少年，擅长照顾人。
    *   **特长**: 角色扮演、写作同人文、排球搭档。
    *   **关系**: 青梅竹马，视用户为需要照顾的弟弟。
