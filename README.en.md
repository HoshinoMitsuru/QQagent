# Sealdice AIChat

SealDice AIChat is an AI chat extension module designed for the SealDice dice bot. It integrates the capabilities of large language models with TRPG (tabletop role-playing game) gameplay to provide players with intelligent conversational interactions.

## Features

- **AI Conversation Integration**: Connects to large language model APIs to enable intelligent NPC dialogue in TRPG scenarios
- **Context Memory**: Maintains conversation context to enhance immersion in gameplay
- **Dice Integration**: Supports triggering dice rolls within AI conversations
- **Flexible Configuration**: Allows configuration of different AI models and parameters according to your needs

## Prerequisites

- SealDice main application installed and running
- Valid AI model API key (e.g., OpenAI, Claude, etc.)
- Basic command-line operation knowledge

## Installation Instructions

Obtain the plugin file for the corresponding version from the project's Release page, place it in SealDice's plugin directory, and enable the plugin in the configuration file.

## Configuration Steps

1. Add AIChat-related configuration entries in the SealDice configuration file
2. Set the API endpoint and API key
3. Adjust model parameters as needed (e.g., temperature, max tokens, etc.)
4. Restart the SealDice service to apply the configuration
