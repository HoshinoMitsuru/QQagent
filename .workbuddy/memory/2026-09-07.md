# 2026-09-07

## 小清澈2.2.js 与 qqai_direct.js 对比评审

- 产出：`review-2.2-vs-qqai_direct.md`（评审报告）
- 结论：两者是同版本 v2.2.0 的两个**并行分支**，非前后迭代。
  - `小清澈2.2.js`（EXT_NAME=`AiChat`，mtime 08-29）：人格提示词较新（加"不要输出思维链"、去掉"海豹助手"身份），但有 3 个未修 bug。
  - `qqai_direct.js`（EXT_NAME=`Mitsuru-AiChat`，mtime 08-12）：修了 A 的 3 个 bug，但新增 `fetchWithTimeout` 时在 `imageToText`（L479）和 `fetchUrlText`（L584）**漏传 timeoutMs**，导致识图/读网页 100% 超时失败；人格提示词为旧版。

### 已定位的 3 个关键 bug（供后续修复参考）
1. `小清澈2.2.js:877` — `isContinuousActive(...)` 第 4 参误传 boolean `sw.continuous`，等效把 1800s 窗口压成 1s，连续对话恒失效。
2. `小清澈2.2.js:665/681` — `.ai off` 被 `stop` 分支提前 return 吞掉，`:681` 的群聊关闭分支是死代码 → 群聊开了陪伴就关不掉。
3. `小清澈2.2.js:797` — `/^(Claritas-小清澈|小清澈)\b/`，`\b` 对 CJK 失效，应改为 `$` 锚定。

### 共有问题
- `autoReplyEnabled` 配置注册但从未读取（死配置）。
- `stripPrefix()` 定义未使用。
- `.ai img` 同时判 `sw.image` 与全局 `imageRecognitionEnabled`，与"私聊强制全开"设计冲突。
- 两版 EXT_NAME 不同可并存，但都注册 `cmdMap["ai"]`/`["aichat"]` 会互相覆盖，且 storage 前缀不同导致历史不互通。

### 建议合并方向
以 `小清澈2.2.js` 为准，移植 qqai_direct 的 3 处修复 + `fetchWithTimeout`（须给识图/网页调用补超时参数，或在函数内做 `Number(timeoutMs)>0 ? ... : 30000` 兜底）。

## 已完成合并 → `小清澈2.3.js`（v2.3.0）

- 基线：`小清澈2.2.js`（人格提示词 + 对话文案全部沿用 2.2）；`EXT_NAME` 保持 `AiChat`，与 2.2 的 storage 前缀一致，历史/人格/群开关可直接继承。
- 移植自 qqai_direct：`.ai off` 独立分支、`@` 正则 `$` 锚定、连续对话布尔短路、`fetchWithTimeout`（并修掉其漏传 timeoutMs 的回归，函数内加 `Number(timeoutMs)>0 ? … : 30000` 兜底）。
- 超时分配：chat 30s / vision 60s / url 15s（三个常量定义在文件头部）。
- 额外改动：删除死代码 `stripPrefix`；`autoReplyEnabled` 改为群聊默认回退且注册默认 `false`（保持"装完群聊不自动回复"的原行为）；`.ai img` 私聊只判 `sw.image`，不再被全局 `imageRecognitionEnabled` 挡住。
- 校验：`node --check 小清澈2.3.js` 通过（SYNTAX_OK）。原 2.2 与 qqai_direct 均未改动。
- 部署注意：若骰上装过 `Mitsuru-AiChat`（qqai_direct 版），需先卸载，否则两插件的 `cmdMap["ai"]` 会互相覆盖。

## 追加：触发词机制调整（仍在 `小清澈2.3.js`）

- `.ai on/off` 语义从「是否回应」改为「是否需要触发词」：群聊 on = 免触发词（默认），off = 须以 `keywordPrefix` 开头；该开关原控制的"是否应答"改为恒定开启（群聊一律应答）。
- 私聊回复不再拼接 `@昵称 ` 前缀（`atString` 改为 `groupId ? ... : ""`），群聊仍保留 @。
- 存储键 `AiChat:autoReply:` → `AiChat:freeTalk:`；函数 `loadAutoReply/saveAutoReply` → `loadFreeTalk/saveFreeTalk`；`resolveSwitches` 的 `autoReply` 字段替换为 `needPrefix`。
- `autoReplyEnabled` 配置项彻底删除（注册 + 读取）。
- 保留豁免：触发词模式下直接发图仍可免触发词唤起。
- 校验：`node --check` 通过；`grep autoReply` 仅剩注释命中。
