# 2026-07-05 工作日志

## 小清澈.js 图片识别功能集成 (v1.6.0 → v1.7.0)

### 任务
将 `D:/Psyche/sealdiceextension/aiplugin4.js` 第 14400 行附近的图片抓取递交给 AI 识别的功能，移植到工作区 `小清澈.js` 中。

### 分析
aiplugin4.js 图片识别核心链路：
- `transformTextToArray(text)` — 解析 CQ 码，提取图片段
- `Image.imageToText(prompt)` — 构造 OpenAI 多模态消息 (image_url + text)，发送到视觉 API
- `sendITTRequest(messages)` — 实际 API 请求
- `transformArrayToContent()` — 将识别结果融入对话上下文

### 实现
在小清澈.js 中新增以下功能（仅修改此文件）：

1. **新增配置项**：`visionApiUrl`、`visionApiKey`、`visionModel`、`imageRecognitionEnabled`、`imageRecognitionPrompt`、`maxImageChars`
2. **新增核心函数**：
   - `generateImageId()` — 唯一 ID 生成
   - `transformTextToArray(text)` — CQ 码解析（移植自 aiplugin4.js）
   - `extractImageUrls(text)` / `extractFirstImageUrl(text)` — 图片 URL 提取
   - `imageToText(imageUrl, prompt, c)` — 视觉 API 识别请求
   - `processMessageWithImages(text, c)` — 消息图片预处理，将 CQ 图片码替换为文字描述
3. **改造 `callAi()`**：在发送给 AI 前先异步处理图片，将图片描述融入对话上下文
4. **新增 `.ai img` 指令**：支持 `.ai img [提示词] + 图片` 主动识别
5. **自动回复集成**：`onNotCommandReceived` 中的消息缓冲区包含 CQ 图片码时，`callAi` 自动识别

### 设计决策
- 采用 image-to-text 模式（先将图片转为文字描述，再融入文本对话），而非直接多模态对话，兼容性更好
- 图片识别默认关闭（`imageRecognitionEnabled: false`），用户需手动开启
- 视觉 API 配置可独立于聊天 API，也可复用（留空则回退到主 API 配置）
